## 快速开始

### 环境要求

- Node.js >= {版本号}
- {数据库} >= {版本号}
- {其他依赖}

### 本地开发

```bash
# 克隆项目
git clone {仓库地址}

# 进入项目目录
cd {项目目录}

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env.local
# 编辑 .env.local 填入必要配置

# 启动开发服务器
npm run dev
```

访问 `http://localhost:{端口号}` 查看应用。

### 构建部署

```bash
# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```
