## 四、组件交互

### 4.1 按钮

| 状态 | 视觉 | 动画 |
|------|------|------|
| 默认 | 正常样式 | 无 |
| 悬停 | 颜色加深 10% | 150ms ease |
| 按下 | 缩放 0.97 | 100ms ease |
| 加载中 | 显示 spinner | 旋转动画 |
| 禁用 | 灰色 + 降低透明度 | 无 |

### 4.2 输入框

| 状态 | 视觉 | 动画 |
|------|------|------|
| 默认 | 灰色边框 | 无 |
| 聚焦 | 蓝色边框 + 外发光 | 200ms ease |
| 错误 | 红色边框 + 提示文字滑入 | 200ms ease |
| 成功 | 绿色边框 + 勾选图标 | 200ms ease |

### 4.3 弹窗

| 行为 | 动画 | 时长 |
|------|------|------|
| 打开 | 遮罩淡入 + 弹窗 scale(0.95→1) + opacity(0→1) | 250ms |
| 关闭 | 遮罩淡出 + 弹窗 scale(1→0.95) + opacity(1→0) | 200ms |
| 点击遮罩关闭 | 同关闭动画 | 200ms |
| ESC 关闭 | 同关闭动画 | 200ms |

### 4.4 下拉菜单

| 行为 | 动画 | 时长 |
|------|------|------|
| 展开 | 高度展开 + 淡入 + 选项逐项滑入 | 200ms |
| 收起 | 高度收起 + 淡出 | 150ms |

## 五、手势交互

### 5.1 移动端手势

| 手势 | 场景 | 行为 | 动画 |
|------|------|------|------|
| 左滑 | 列表项 | 显示操作按钮 | 弹性滑动 |
| 右滑 | 详情页 | 返回上一页 | 跟手滑动 |

| 上拉 | 页面底部 | 加载更多 | 底部加载指示器 |
| 长按 | 列表项 | 进入选择模式 | 缩放震动反馈 |
| 双指缩放 | 图片 | 放大/缩小 | 跟手缩放 |
