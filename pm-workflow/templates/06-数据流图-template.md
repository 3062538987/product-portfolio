## 三、核心数据流

### 3.1 {数据流 1：如——用户登录流程}

```
用户输入账号密码
    ↓
前端表单验证
    ↓
POST /api/login
    ↓
后端验证账号密码
    ↓
生成 JWT Token
    ↓
返回 Token + 用户信息
    ↓
前端存储 Token (localStorage/Cookie)
    ↓
跳转到首页，更新用户状态
```

### 3.2 {数据流 2：如——列表数据加载}

```
页面加载
    ↓
触发 API 请求 (GET /api/list?page=1&size=20)
    ↓
后端查询数据库
    ↓
返回分页数据
    ↓
前端更新列表状态
    ↓
渲染列表组件
```

### 3.3 {数据流 3：如——数据提交}

```
用户填写表单
    ↓
前端表单验证
    ↓
POST /api/submit
    ↓
后端数据校验
    ↓
写入数据库
    ↓
返回成功/失败响应
    ↓
前端更新状态 + 展示反馈
```

## 六、错误处理

| 错误类型 | 处理方式 | 用户提示 |
|----------|----------|----------|
| 网络错误 | 重试 3 次 + 展示错误提示 | "网络连接失败，请检查网络" |
| 401 未授权 | 跳转登录页 | "登录已过期，请重新登录" |
| 404 未找到 | 展示空状态页面 | "页面不存在" |
| 500 服务器错误 | 展示错误提示 | "服务器繁忙，请稍后重试" |
| 数据校验失败 | 展示表单错误 | 具体字段错误提示 |
