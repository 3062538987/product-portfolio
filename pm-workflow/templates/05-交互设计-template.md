## 二、动效规范

### 2.1 缓动曲线

| 用途 | 曲线 | 时长 | 示例 |
|------|------|------|------|
| 入场动画 | ease-out | 300ms | 弹窗/卡片出现 |
| 离场动画 | ease-in | 200ms | 弹窗/卡片消失 |
| 悬停效果 | ease-in-out | 150ms | 按钮 hover |
| 页面切换 | ease-in-out | 400ms | 路由跳转 |

### 2.2 动画属性

| 属性 | 推荐值 | 说明 |
|------|--------|------|
| opacity | 0 → 1 | 淡入淡出 |
| transform | translateY(10px) → 0 | 上移入场 |
| scale | 0.95 → 1 | 缩放入场 |
| height | auto | 展开/折叠 |

## 三、组件交互

### 3.1 按钮

| 状态 | 视觉表现 | 触发条件 |
|------|----------|----------|
| 默认 | {默认样式} | 页面加载 |
| 悬停 | {颜色加深/阴影增强} | 鼠标移入 |
| 点击 | {缩放 0.97/颜色最暗} | 鼠标按下 |
| 禁用 | {灰色/降低透明度} | 条件不满足 |
| 加载中 | {显示 loading 图标} | 异步操作中 |

### 3.2 弹窗/模态框

| 触发方式 | 动画 |
|----------|------|
| 打开 | 背景遮罩淡入 + 弹窗缩放+淡入 |
| 关闭 | 背景遮罩淡出 + 弹窗缩放+淡出 |
| 关闭方式 | 点击关闭按钮 / 点击遮罩 / ESC 键 |

### 3.3 表单

| 交互 | 说明 |
|------|------|
| 输入聚焦 | 边框高亮 + 外发光 |
| 输入错误 | 红色边框 + 错误提示文字 |
| 输入成功 | 绿色边框 + 勾选图标 |
| 提交 | 按钮变为 loading 状态，禁用重复提交 |

### 3.4 列表/卡片

| 交互 | 说明 |
|------|------|
| 悬停 | 阴影增强 + 轻微上移 |
| 拖拽 | 卡片半透明 + 目标区域高亮 |
| 删除 | 滑出动画 + 确认提示 |
| 加载更多 | 滚动到底部触发 / 点击加载更多按钮 |

## 四、页面过渡

| 过渡类型 | 动画 | 时长 |
|----------|------|------|
| 页面进入 | 从右滑入 + 淡入 | 300ms |
| 页面返回 | 从左滑入 + 淡入 | 300ms |
| 模态框打开 | 缩放 + 淡入 | 250ms |
| 模态框关闭 | 缩放 + 淡出 | 200ms |

## 五、微交互

## 六、手势交互（移动端）

| 手势 | 场景 | 行为 |
|------|------|------|
| 左滑 | 列表项 | 显示操作按钮（删除/编辑） |
| 下拉 | 页面顶部 | 触发刷新 |
| 上拉 | 页面底部 | 加载更多 |
| 长按 | 列表项/图片 | 进入选择模式/预览 |
