## 四、各区域内容

### 4.1 导航栏
- 背景：白色，底部 1px `#E5E7EB` 边线
- 姓名"张三"左对齐，20px Bold
- 导航链接：`项目作品` / `关于我` / `文章`，14px，`#6B7280`
- 当前区域（项目作品）底部 2px `#3B82F6` 下划线
- 下载按钮：`#3B82F6` 填充，白色文字，8px 圆角，高度 38px

### 4.2 Hero 首屏
- 背景：白色 + 25% 透明度 `#DBEAFE` 渐变叠加
- 布局：左侧内容区（姓名 + 标签 + 指标 + 按钮），右侧头像（120×120，圆角 16px）
- 头像：120×120（桌面）→ 140×140（平板）→ 100×100（移动），蓝色浅底 + 首字"张"
- 定位语：`B端产品实习生 · 2027届秋招`
- 标签：4 个技能标签，`#DBEAFE` 浅蓝背景，`#3B82F6` 蓝色文字
- 核心指标：3 个指标卡片（170×80），差异化背景色（绿/蓝/橙），数字 28px Bold + 标签 14px + 说明 11px
- CTA 按钮：主按钮蓝底白字 + 次按钮蓝框蓝字，高度 44px（符合设计系统规范）

### 4.3 项目作品集
- 布局：2 列网格（960px 内容区，每列 460px，间距 20px）
- 排布：Card 1（展开态，左列）+ Card 2（折叠态，右列）→ Card 3（折叠态，左列）+ Card 4（折叠态，右列）
- Card 1（展开态）：蓝色边框 `#3B82F6` + 浅蓝头部 + 模块化内容（每个模块间有 `#E5E7EB` 分隔线）
- Card 2-4（折叠态）：灰色边框 `#E5E7EB`，标题 + 标签 + 描述 + 3 指标
- 展开态头部标注"展开中"标签
- 指标颜色：绿色（正向）、蓝色（中性）、橙色（强调）

### 4.4 关于我
- 背景：`#F9FAFB` 浅灰（与白色交替）
- 布局：两栏（左栏 60% 个人陈述 + 时间线，右栏 40% 技能标签）
- 左侧蓝色竖线 + 浅蓝背景职业目标卡片
- 左侧时间线：蓝色圆点 + 连接线，3 条教育/经历
- 右侧 8 个技能标签，浅蓝背景，2 行 × 4 列排列

### 4.5 精选文章
- 背景：白色
- 3 篇文章卡片，左侧 4px 蓝色竖线装饰
- 每张卡片：标题 + 日期 + 描述

### 4.6 联系方式
- 背景：`#F9FAFB` 浅灰
- 邮箱 + 微信 + GitHub 链接
- 4 个社交平台按钮（GitHub/LinkedIn/掘金/知乎），蓝色边框

### 4.7 页脚
- 顶部 1px 分割线
- 版权信息，12px `#9CA3AF`

## 五、与低保真的对比

| 维度 | 低保真 | 高保真 |
|---|---|---|
| 颜色 | 灰度 `#E8E8E8` / `#999999` | 品牌蓝 `#3B82F6` + 完整配色 |
| 边框 | 虚线 `[6,4]` | 实线 `#E5E7EB` |
| 填充 | 灰色 `#E8E8E8` | 白色 + 浅蓝 `#DBEAFE` + 浅灰 `#F9FAFB` |
| 阴影 | 无 | `shadow-sm` / `shadow-md` |
| 圆角 | 无 | 卡片 12px / 按钮 8px / 标签 4px |
| 内容 | 占位符 `[头像占位]` | 示例真实内容 |
| 动效标注 | 箭头文字 `↘ 点击展开` | 无（静态视觉稿） |

## 七、v2 排版优化记录（2026-08-05）

### 修复的问题
| 问题 | 修复前 | 修复后 |
|---|---|---|
| Projects-BG 偏移 | `x: 158` 未居中 | `x: 0`，960px 内容区居中 |
| Section 标题偏移 | `x: 540` 居中定位错误 | `x: 160`，左对齐到内容区 |
| 卡片内容溢出 | 文字宽度 596px > 卡片 540px | 文字宽度 ≤ 492px |

| 卡片布局混乱 | 单列交错排列 | 2 列网格，统一间距 |
| 信息密度过高 | 展开态无模块分隔 | 6 个模块间添加 `#E5E7EB` 分隔线 |
| 头像过大 | 180×180 | 120×120 |
| 指标无容器 | 纯文字排列 | 3 个指标卡片（170×80），差异化背景色 |
| 页面过长 | 3876px | 3427px（减少 12%） |
