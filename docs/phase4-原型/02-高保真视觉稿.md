## 四、各区域内容

### 4.1 导航栏
- 背景：白色，底部 1px `#E5E7EB` 边线
- 姓名"张三"左对齐，20px Bold
- 导航链接：`项目作品` / `关于我` / `文章`，14px，`#6B7280`
- 当前区域（项目作品）底部 2px `#3B82F6` 下划线
- 下载按钮：`#3B82F6` 填充，白色文字，8px 圆角，高度 38px

### 4.2 Hero 首屏
- 背景：白色 + 25% 透明度 `#DBEAFE` 渐变叠加
- 头像：180×180（桌面）→ 140×140（平板）→ 100×100（移动），蓝色浅底 + 首字"张"
- 定位语：`B端产品实习生 · 2027届秋招`
- 标签：4 个技能标签，`#DBEAFE` 浅蓝背景，`#3B82F6` 蓝色文字
- 核心指标：3 个指标（转化率/月活/满意度），颜色区分（绿/蓝/橙）
- CTA 按钮：主按钮蓝底白字 + 次按钮蓝框蓝字

### 4.3 项目作品集
- Card 1（展开态）：蓝色边框 + 浅蓝头部 + 完整内容（背景、角色、方案、对比、复盘、交付物）
- Card 2-4（折叠态）：灰色边框，标题 + 标签 + 描述 + 3 指标
- 展开态头部标注"展开中"标签
- 指标颜色：绿色（正向）、蓝色（中性）、橙色（强调）

### 4.4 关于我
- 背景：`#F9FAFB` 浅灰（与白色交替）
- 左侧蓝色竖线 + 浅蓝背景职业目标卡片
- 右侧时间线：蓝色圆点 + 连接线，3 条教育/经历
- 8 个技能标签，浅蓝背景，2 行排列

### 4.5 精选文章
- 背景：白色
- 3 篇文章卡片，左侧 4px 蓝色竖线装饰
- 每张卡片：标题 + 日期 + 描述

### 4.6 联系方式
- 背景：`#F9FAFB` 浅灰
- 邮箱 + 微信 + GitHub 链接
- 4 个社交平台按钮（GitHub/LinkedIn/掘金/知乎），蓝色边框

### 4.7 页脚
- 顶部 1px 分割线
- 版权信息，12px `#9CA3AF`

## 五、与低保真的对比

| 维度 | 低保真 | 高保真 |
|---|---|---|
| 颜色 | 灰度 `#E8E8E8` / `#999999` | 品牌蓝 `#3B82F6` + 完整配色 |
| 边框 | 虚线 `[6,4]` | 实线 `#E5E7EB` |
| 填充 | 灰色 `#E8E8E8` | 白色 + 浅蓝 `#DBEAFE` + 浅灰 `#F9FAFB` |
| 阴影 | 无 | `shadow-sm` / `shadow-md` |
| 圆角 | 无 | 卡片 12px / 按钮 8px / 标签 4px |
| 内容 | 占位符 `[头像占位]` | 示例真实内容 |
| 动效标注 | 箭头文字 `↘ 点击展开` | 无（静态视觉稿） |
