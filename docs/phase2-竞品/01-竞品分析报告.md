## 竞品 A：张智博个人作品集

- **网址**：https://www.zzb9.cn
- **形态**：独立网站（Next.js 静态导出 + GitHub Pages）
- **作者背景**：在校学生，关注 AI 工具应用、产品设计、网站建设

### 页面结构

```
首页（克制的信息展示）
├── 个人简介 + 定位
├── 项目卡片列表（6个项目，按方向分类）
│   ├── 智能设备
│   ├── 酒店产品
│   ├── 数字文化
│   ├── 电商工具
│   ├── 企业网站
│   └── 个人品牌
└── 每个项目 → 独立详情页
```

### 亮点

| 维度 | 评价 | 说明 |
|---|---|---|
| **内容深度** | ★★★★★ | 每个项目有完整的叙事链：问题→场景→边界→设计→实现→测试→迭代，不是只展示结果 |
| **项目叙事** | ★★★★★ | 采用"发现真实问题 → 还原使用场景 → 明确项目边界 → 设计产品结构 → 技术实现 → 实际使用中发现问题 → 调整 → 整理成果"的闭环逻辑 |
| **技术方案** | ★★★★☆ | Next.js 静态导出 + GitHub Pages + GitHub Actions 自动部署，不需要服务器，维护成本极低 |
| **首页克制** | ★★★★☆ | 首页不堆砌成果，项目用卡片分类展示，点击进入详情页 |
| **SEO 友好** | ★★★★☆ | 独立页面，搜索引擎可抓取，AI 系统可理解人物与作品关系 |

### 不足

| 维度 | 评价 | 说明 |
|---|---|---|
| **视觉设计** | ★★★☆☆ | 设计偏功能化，配色和排版较朴素，缺乏品牌感 |
| **首屏冲击力** | ★★☆☆☆ | 首屏信息密度偏低，15 秒内难以快速抓住面试官注意力 |
| **数据可视化** | ★★☆☆☆ | 缺少 Before/After 数据对比图表，项目成果量化不够直观 |
| **移动端体验** | ★★★☆☆ | 基础响应式可用，但细节打磨不足 |

### 可借鉴点

1. **项目叙事结构**：问题→场景→边界→方案→实现→测试→迭代的闭环逻辑，值得直接复用
2. **部署方案**：GitHub Pages + GitHub Actions 自动部署，正是我们计划采用的方案，验证了可行性
3. **首页克制原则**：不堆砌内容，用卡片分类展示，点击进入详情
4. **独立域名**：使用个人域名（zzb9.cn），比 github.io 更有品牌感

### 可改进方向（我们的差异化机会）

1. 在视觉设计上做更多投入，提升品牌感和专业度
2. 大幅强化数据可视化（Before/After 对比图表）
3. 优化首屏设计，让面试官 15 秒内形成印象
4. 增加 PDF 一键导出功能

## 竞品 B：Kane Sherwell 作品集

- **网址**：https://kanesherwell.com
- **形态**：独立网站（Webflow 搭建）
- **作者背景**：Senior Product Manager，聚焦产品策略和无缝交付


### 亮点

| 维度 | 评价 | 说明 |
|---|---|---|
| **视觉设计** | ★★★★★ | Webflow 动画 + 大胆渐变背景 + 叙事流设计，视觉冲击力强 |
| **首屏冲击力** | ★★★★★ | 动态渐变背景 + 一句话核心定位，打开瞬间抓住注意力 |
| **叙事能力** | ★★★★★ | 项目展示采用 Storytelling 流，读起来像在看一个故事，而不是在看简历 |
| **品牌感** | ★★★★★ | 整体设计统一，配色、字体、动效形成强烈的个人品牌印象 |
| **动效运用** | ★★★★☆ | 适度的滚动动画和渐变动效，提升浏览体验但不花哨 |

### 不足

| 维度 | 评价 | 说明 |
|---|---|---|
| **内容深度** | ★★★☆☆ | 偏向展示结果和亮点，缺少完整的决策过程拆解 |
| **数据量化** | ★★★☆☆ | 项目成果有数据，但缺少 Before/After 对比的直观呈现 |

| **中文适配** | ★☆☆☆☆ | 纯英文，对国内秋招场景参考价值有限（但设计思路值得借鉴） |

1. **Hero 首屏设计**：动态渐变背景 + 一句话核心定位，15 秒抓住注意力

3. **品牌一致性**：配色、字体、动效全局统一，形成强烈的个人品牌
4. **单页滚动**：信息密度适中，浏览体验流畅

### 可改进方向（我们的差异化机会）

1. 在保持视觉冲击力的同时，增加项目决策过程的深度展示
2. 用 Before/After 数据对比图表替代纯文字描述
3. 采用开源技术栈（React + Tailwind），降低模仿门槛，同时体现技术能力

## 竞品 C：Notion 作品集（秋招 PM 常用方案）

- **形态**：Notion 公开页面，分享链接即作品集
- **典型用户**：秋招应届生 PM，快速搭建零成本

### 页面结构

```
Notion 页面（长滚动）
├── 个人头像 + 简介
├── 项目 1
│   ├── 项目背景
│   ├── 我的角色
│   ├── 关键成果
│   └── 截图/原型图
├── 项目 2（同上）
├── 项目 3（同上）
└── 联系方式
```

### 亮点

| 维度 | 评价 | 说明 |
|---|---|---|
| **搭建效率** | ★★★★★ | 零代码，10 分钟即可完成，适合时间紧迫的秋招场景 |
| **内容编辑** | ★★★★★ | 随时在线修改，无需部署，更新即生效 |
| **结构化** | ★★★★☆ | Notion 的数据库和页面嵌套功能，天然适合结构化内容展示 |
| **成本** | ★★★★★ | 完全免费 |
| **分享便捷** | ★★★★★ | 一个链接即可分享，支持密码保护 |

### 不足

| 维度 | 评价 | 说明 |
|---|---|---|
| **品牌感** | ★★☆☆☆ | 页面顶部有 Notion 标识，URL 是 notion.so 域名，缺乏个人品牌感 |
| **加载速度** | ★★★☆☆ | Notion 页面加载较慢，首屏渲染需要 2-3 秒 |
| **视觉设计** | ★★☆☆☆ | 受限于 Notion 模板，排版和配色可定制性低 |
| **移动端** | ★★★☆☆ | 基础可用，但 Notion 页面在移动端阅读体验一般 |
| **差异化** | ★☆☆☆☆ | 越来越多人用 Notion 做作品集，同质化严重，难以脱颖而出 |
| **SEO** | ★☆☆☆☆ | Notion 页面搜索引擎收录效果差，基本无法被搜索到 |

### 可借鉴点

1. **内容更新便利性**：我们的网站也应该做到数据驱动，修改 JSON 文件即可更新内容，不需要改代码
2. **结构化思维**：Notion 的数据库/页面嵌套逻辑，启发我们做好数据文件的结构设计

### 可改进方向（我们的差异化机会）

1. 网站形态天然比 Notion 有更强的品牌感和差异化
2. 加载速度大幅优于 Notion
3. 视觉设计自由度更高，不受模板限制
4. 独立域名 + SEO 优化，可被搜索引擎收录

### 不足

| 维度 | 评价 | 说明 |

2. **离线可用性**：考虑在面试现场没有网络时的展示方案

### 可改进方向（我们的差异化机会）

1. 网站 + PDF 双模：网站作为主展示，PDF 作为邮件补充
2. 网站支持一键导出 PDF，兼顾两种场景

## 核心洞察

### 1. 独立网站是最佳形态

- Notion 和 PDF 在差异化、品牌感、SEO 上全面落后
- 独立网站在内容深度、视觉设计、品牌感上都有不可替代的优势
- 竞品 B 证明了好的设计能大幅提升阅读体验

### 2. 我们的差异化机会

| 机会点 | 竞品现状 | 我们的策略 |
|---|---|---|
| 数据可视化 | 竞品普遍缺少量化对比 | 每个项目必须有 Before/After 数据对比图表 |
| 项目叙事深度 | 要么深度够但设计差（A），要么设计好但深度不够（B） | 兼顾深度和设计，用 Problem→Solution→Impact 结构 |
| 首屏设计 | 多数竞品首屏信息密度不足 | Hero 渐变背景 + 核心定位 + 3 个关键指标，15 秒形成印象 |
| PDF 双模 | 竞品只有单一形态 | 网站主展示 + 一键导出 PDF，覆盖面试和邮件两种场景 |
| 产品全流程文档 | 竞品只展示项目结果 | 网站展示精简版 + 附件区放完整 PRD/流程图，体现全流程能力 |

### 3. 竞品 A 的技术方案验证

竞品 A 采用 Next.js 静态导出 + GitHub Pages + GitHub Actions 自动部署，与我们的 React + GitHub Pages 方案高度一致，验证了该方案的可行性。同时竞品 A 使用了独立域名，说明 GitHub Pages 绑域名是成熟方案。

### 4. 竞品 C 的教训

Notion 作品的同质化越来越严重，说明单纯"有作品集"已经不够，必须做到"作品集本身也是一件作品"。我们的网站从需求调研到上线复盘的完整流程，正是差异化所在。

---

## 结论

**我们的作品集网站应该做到：**

1. 内容深度对标竞品 A（完整叙事链），设计感对标竞品 B（视觉冲击力）
2. 每个项目用 Before/After 数据可视化展示成果，这是所有竞品都缺失的
3. 首屏 15 秒内传递核心印象，用渐变背景 + 关键指标数字抓住注意力
4. 保留 PDF 导出功能，覆盖邮件发送场景
5. 网站本身作为产品项目展示，附完整 PRD 和流程图，体现全流程能力
