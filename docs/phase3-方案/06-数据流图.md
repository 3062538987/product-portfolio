## 二、数据文件 → 组件映射表

| 数据文件 | 导出类型 | 使用组件 | 数据用途 |
|---|---|---|---|
| `profile.ts` | `Profile` | `HeroSection` | 姓名、岗位、定位语 |
| `profile.ts` | `Profile` | `Navbar` | 导航栏姓名（点击回顶部） |
| `profile.ts` | `Profile` | `AboutSection` | 个人陈述、职业目标 |
| `profile.ts` | `Profile` | `ContactSection` | 邮箱、LinkedIn |
| `profile.ts` | `Profile` | `PDFResume` | PDF 简历头部信息 |
| `profile.ts` | `Profile` | `Footer` | Copyright 年份 + 姓名 |
| `projects.ts` | `ProjectsData` | `ProjectsSection` | 遍历渲染项目卡片列表 |
| `projects.ts` | `ProjectsData` | `ProjectCard` | 单个项目全部内容 |
| `projects.ts` | `ProjectsData` | `PDFResume` | PDF 简历项目摘要 |
| `articles.ts` | `ArticlesData` | `ArticlesSection` | 遍历渲染文章卡片列表 |
| `articles.ts` | `ArticlesData` | `ArticleCard` | 单篇文章内容 |
| `articles.ts` | `ArticlesData` | `Navbar` | 判断是否显示"文章"导航链接 |

## 三、数据更新流程

```
用户修改 src/data/ 文件
        │
        ▼
    git commit + push
        │
        ▼
  GitHub Actions 触发
        │
        ▼
    npm run build
        │
        ▼
  新数据被打包进 dist/
        │
        ▼
  部署到 GitHub Pages
        │
        ▼
  网站内容自动更新
```

**无需改代码，修改数据文件即可更新网站内容。**

## 四、条件渲染逻辑

| 条件 | 行为 |
|---|---|
| `articles.length === 0` | `ArticlesSection` 不渲染，导航栏"文章"链接隐藏 |
| `articles.length > 0` | `ArticlesSection` 渲染，导航栏显示"文章"链接 |
| `projects.length ≥ 2` | 正常渲染（理论上至少 2 个项目） |
| 图片加载失败 | 显示占位色块 `bg-gray-100`，不影响布局 |

## 五、数据流特点

- **单向数据流**：数据从 `src/data/` → `App.tsx` → 子组件，子组件不修改数据
- **无全局状态**：不使用 Redux/Zustand，纯 props 传递
- **无异步请求**：所有数据在构建时打包，无运行时 API 调用
- **类型安全**：TypeScript 接口约束数据格式，编译时检查
