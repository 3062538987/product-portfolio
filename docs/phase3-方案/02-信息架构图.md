## 一、网站整体信息架构

```
首页 (单页应用)
│
├── 导航栏 (全局固定)
│   ├── 项目作品 → 锚点 #projects
│   ├── 关于我   → 锚点 #about
│   ├── 文章     → 锚点 #articles
│   └── [下载简历] → 触发 PDF 导出
│
├── 1. Hero 首屏
│   ├── 姓名
│   ├── 岗位：B端产品经理
│   ├── 一句话定位
│   └── CTA 按钮 → 滚动到 #projects
│
├── 2. 项目作品集 (#projects)
│   ├── 项目卡片 1
│   │   ├── 折叠态：项目名称 + 一句话概述 + 3个关键指标
│   │   └── 展开态：背景与挑战 / 我的角色 / 方案与决策 / 数据对比 / 复盘
│   ├── 项目卡片 2
│   │   ├── 折叠态：(同上)
│   │   └── 展开态：(同上)
│   └── 项目卡片 3
│       ├── 折叠态：(同上)
│       └── 展开态：(同上)
│
├── 3. 关于我 (#about)
│   ├── 个人陈述（2-3句话）
│   └── 一句话职业目标
│
├── 4. 精选文章 (#articles)
│   ├── 文章卡片 1（如有）
│   │   ├── 标题
│   │   ├── 日期
│   │   ├── 摘要
│   │   └── 外部链接
│   └── 文章卡片 2（如有）
│
├── 5. 联系方式
│   ├── 邮箱
│   └── LinkedIn
│
└── 6. 页脚
    └── Copyright © 2026 [姓名]
```

## 二、导航结构

### 全局导航（桌面端）

```
┌────────────────────────────────────────────────┐
│  [姓名]    项目作品  |  关于我  |  文章    [下载简历] │
└────────────────────────────────────────────────┘
```

- 左侧：姓名（点击回到顶部）
- 中间：三个锚点链接，当前区域高亮
- 右侧：PDF 下载按钮（主色按钮，突出）

### 移动端导航

```
┌──────────────────────────┐
│  [姓名]          [☰]     │  ← 汉堡菜单
└──────────────────────────┘
        点击展开
┌──────────────────────────┐
│  项目作品                 │
│  关于我                   │
│  文章                     │
│  ─────────────           │
│  下载简历                 │
└──────────────────────────┘
```

## 三、内容层级关系

```
Hero (1级)
  └── 项目作品集 (1级)
        ├── 项目卡片 1 (2级)
        │     ├── 折叠态 (3级)
        │     │     ├── 项目名称
        │     │     ├── 一句话概述
        │     │     └── 关键指标 ×3
        │     └── 展开态 (3级)
        │           ├── 背景与挑战
        │           ├── 我的角色
        │           ├── 方案与决策
        │           ├── 数据对比 (Before/After)
        │           └── 复盘与反思
        ├── 项目卡片 2 (2级)
        └── 项目卡片 3 (2级)
  ├── 关于我 (1级)
  ├── 精选文章 (1级，可隐藏)
  │     ├── 文章卡片 1 (2级)
  │     └── 文章卡片 2 (2级)
  ├── 联系方式 (1级)
  └── 页脚 (1级)
```

## 四、页面间导航规则

| 起点 | 终点 | 触发方式 |
|---|---|---|
| 导航栏 | 各区域 | 点击锚点链接，平滑滚动 |
| Hero CTA 按钮 | 项目作品集 | 点击「查看作品」按钮 |
| 项目卡片折叠态 | 项目卡片展开态 | 点击「展开」按钮 |
| 项目卡片展开态 | 项目卡片折叠态 | 点击「收起」按钮 |
| 任意位置 | 顶部 | 点击导航栏姓名 |
| 任意位置 | PDF 下载 | 点击「下载简历」按钮 |
| 外部链接 | 文章详情 | 点击文章卡片 → 新标签页打开 |

## 五、状态说明

| 状态 | 说明 |
|---|---|
| 空状态 | 文章模块无内容时，整个 `#articles` 区域隐藏 |
| 加载态 | 纯静态，无异步请求，无加载态 |
| 错误态 | 纯静态，无错误态需求 |
| 单卡片展开 | 同一时间只有一个项目卡片处于展开态，展开新的自动收起旧的 |
