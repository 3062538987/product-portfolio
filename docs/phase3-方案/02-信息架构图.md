## 一、面试官浏览路径（核心用户旅程）

这是最重要的信息架构设计依据——面试官从打开网站到形成印象的完整路径：

```
打开网站 (0s)
    │
    ▼
[首屏可见] Hero — 3秒内知道你是谁、做什么的
    │
    ▼
[首屏可见] 第1个项目卡片（折叠态）— 看项目名称 + 一句话概述 + 3个关键指标
    │   ├─ 有兴趣 → 展开看完整 STAR 描述 (2-3分钟)
    │   └─ 没兴趣 → 继续滚动
    │
    ▼
[滚动1屏] 第2个项目卡片（折叠态）— 同上
    │
    ▼
[滚动2屏] 第3个项目卡片（折叠态）— 同上
    │
    ▼
[滚动3屏] 关于我（轻量版）— 个人陈述 + 职业目标
    │
    ▼
[滚动4屏] 精选文章（如有）— 产品思考
    │
    ▼
[底部] 联系方式 + 页脚
    │
    ▼
📎 点击 [下载简历] → 获得 PDF 版本
```

**关键洞察：** 面试官在前 2 屏（首屏 + 第 1 个项目卡片）做出是否继续阅读的决定。所以 Hero 和第一个项目卡片必须是最强的。

## 二、网站整体信息架构

```
首页 (单页应用)
│
├── 导航栏 (全局固定，滚动时加阴影)
│   ├── 项目作品 → 锚点 #projects
│   ├── 关于我   → 锚点 #about
│   ├── 文章     → 锚点 #articles
│   └── [下载简历] → 触发 PDF 导出
│
├── 1. Hero 首屏 ⭐ 首屏可见
│   ├── 姓名（大字）
│   ├── 岗位：B端产品经理
│   ├── 一句话定位
│   └── CTA 按钮「查看作品 ↓」→ 滚动到 #projects
│
├── 2. 项目作品集 (#projects) ⭐ 核心区域，80%篇幅
│   ├── 项目卡片 1（最重要，放最前面）
│   │   ├── 折叠态：项目名称 + 一句话概述 + 3个关键指标数字 + [展开 ↓]
│   │   │   └── 面试官 15 秒可扫读完
│   │   └── 展开态：
│   │       ├── 背景与挑战
│   │       ├── 我的角色
│   │       ├── 方案与决策逻辑
│   │       ├── 数据对比 (Before/After，Power BI 图表)
│   │       └── 复盘与反思
│   ├── 项目卡片 2（同上结构）
│   └── 项目卡片 3（同上结构）
│
├── 3. 关于我 (#about) — 轻量版，1屏
│   ├── 个人陈述（2-3句话，故事化）
│   └── 一句话职业目标
│
├── 4. 精选文章 (#articles) — 可隐藏，0-2篇
│   ├── 文章卡片 1（如有）
│   │   ├── 标题
│   │   ├── 日期
│   │   ├── 摘要（1-2句话）
│   │   └── 外部链接（新标签页打开）
│   └── 文章卡片 2（如有）
│
├── 5. 联系方式
│   ├── 邮箱
│   └── LinkedIn
│
└── 6. 页脚
    └── Copyright © 2026 [姓名]
```

## 三、首屏可见内容 vs 滚动内容

### 桌面端（1280px 视口，约 800px 首屏高度）

```
┌─────────────────────────────────┐
│  导航栏                          │  ← 固定
├─────────────────────────────────┤
│                                 │
│  Hero 首屏                      │  ← 首屏可见
│  (姓名 + 定位 + CTA 按钮)        │
│                                 │
├─────────────────────────────────┤  ← 首屏折叠线
│  项目卡片 1（折叠态）             │  ← 首屏可见（部分）
│  名称 + 概述 + 3个指标 + [展开]  │
│                                 │
├─────────────────────────────────┤
│  项目卡片 1（展开后可滚动）       │  ← 需滚动
│  STAR 完整描述                  │
├─────────────────────────────────┤
│  项目卡片 2                      │
│  项目卡片 3                      │
├─────────────────────────────────┤
│  关于我                          │
│  精选文章（如有）                 │
│  联系方式 + 页脚                 │
└─────────────────────────────────┘
```

### 移动端（375px 视口，约 600px 首屏高度）

```
┌───────────────────┐
│  汉堡菜单          │  ← 固定
├───────────────────┤
│  Hero 首屏         │  ← 首屏可见
│  (全宽，文字缩小)   │
├───────────────────┤  ← 首屏折叠线
│  项目卡片 1（折叠） │  ← 首屏可见
│  全宽堆叠          │
├───────────────────┤
│  展开后全宽滚动    │  ← 需滚动
│  ...              │
└───────────────────┘
```

## 四、导航结构

### 全局导航（桌面端）

```
┌────────────────────────────────────────────────┐
│  [姓名]    项目作品  |  关于我  |  文章    [下载简历] │
│  (左)        (中)           (中)      (中)    (右)  │
└────────────────────────────────────────────────┘
```

- 左侧：姓名，点击回到顶部，字体加粗
- 中间：三个锚点链接，当前所在区域对应的链接高亮（主色下划线）
- 右侧：PDF 下载按钮（主色填充按钮，突出）
- 滚动行为：导航栏始终固定，滚动超过 100px 后添加底部阴影

### 移动端导航

```
折叠态：                   展开态：
┌──────────────────┐    ┌──────────────────┐
│  [姓名]    [☰]    │    │  [姓名]    [✕]    │
└──────────────────┘    ├──────────────────┤
                        │  项目作品          │
                        │  关于我            │
                        │  文章              │
                        │  ─────────        │
                        │  下载简历 [按钮]    │
                        └──────────────────┘
```

- 展开时从顶部下滑，覆盖全屏
- 点击菜单项后自动收起，平滑滚动到对应区域
- 背景半透明遮罩

## 五、内容层级与视觉权重

| 区域 | 信息层级 | 视觉权重 | 占据篇幅 | 面试官阅读时间 |
|---|---|---|---|---|
| Hero | 1 级 | ⭐⭐⭐ | 1 屏 | 3 秒 |
| 项目卡片（折叠态） | 1 级 | ⭐⭐⭐⭐⭐ | 每个 0.3 屏 | 15 秒/个 |
| 项目卡片（展开态） | 2 级 | ⭐⭐⭐⭐ | 每个 1-2 屏 | 2-3 分钟/个 |
| 关于我 | 1 级 | ⭐⭐ | 0.5 屏 | 10 秒 |
| 精选文章 | 1 级（可隐藏） | ⭐ | 0.3 屏/篇 | 10 秒 |
| 联系方式 | 1 级 | ⭐ | 0.2 屏 | 5 秒 |
| 页脚 | 3 级 | — | 0.1 屏 | 0 秒 |

## 六、页面间导航规则

| 起点 | 终点 | 触发方式 | 行为 |
|---|---|---|---|
| 导航栏链接 | 各区域 | 点击 | 平滑滚动（`scroll-behavior: smooth`），偏移导航栏高度 |
| Hero CTA 按钮 | 项目作品集 | 点击 | 平滑滚动到第一个项目卡片 |
| 项目卡片折叠态 | 展开态 | 点击「展开」按钮 | 手风琴模式，展开当前、收起其他 |
| 项目卡片展开态 | 折叠态 | 点击「收起」按钮 | 平滑收起 |
| 任意位置 | 顶部 | 点击导航栏姓名 | 回到顶部 |
| 任意位置 | PDF 下载 | 点击「下载简历」按钮 | 触发 react-to-print 打印对话框 |
| 文章卡片 | 文章详情 | 点击 | 新标签页打开外部链接 |

## 七、状态说明

| 状态 | 触发条件 | 处理方式 |
|---|---|---|
| 空状态 | 文章模块无内容 | `#articles` 整个区域隐藏，导航栏中「文章」链接同步隐藏 |
| 加载态 | — | 纯静态站点，无异步请求，无加载态 |
| 错误态 | — | 纯静态，无运行时错误需求 |
| 手风琴模式 | 展开项目卡片 | 同一时间只有 1 个卡片处于展开态，展开新的自动收起旧的 |
| 导航高亮 | 滚动到对应区域 | 使用 Intersection Observer 监听，当前区域对应导航链接高亮 |
| 导航阴影 | 滚动超过 100px | 导航栏底部添加阴影，提升层次感 |
