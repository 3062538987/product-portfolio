# 3.5 交互设计

> 所属阶段：阶段 3 — 方案设计
> 日期：2026-08-05
> 状态：讨论中
> 说明：定义所有页面交互行为、动效规范、过渡逻辑和微交互

---

## 一、交互设计原则

| 原则 | 说明 | 落地方式 |
|---|---|---|
| 即时反馈 | 任何操作 100ms 内必须有视觉反馈 | hover 状态、按钮 active 态、过渡动画 |
| 减少认知负荷 | 手风琴模式一次只展开一个，避免面试官信息过载 | `useAccordion` Hook |
| 符合直觉 | 滚动=向下阅读，点击=展开/跳转，符合 Web 浏览习惯 | 锚点平滑滚动、点击展开 |
| 可预测 | 同类元素行为一致，导航高亮始终准确 | Intersection Observer 实时监听 |
| 克制 | 动效不超过 300ms，不做弹跳、缩放等炫技动效 | 统一 timing 规范 |

## 二、全局动效规范

### 2.1 时长与缓动

| 类型 | 时长 | 缓动函数 | 用途 |
|---|---|---|---|
| 微交互 | 150ms | `ease-out` | 按钮 hover、链接变色、图标旋转 |
| 标准过渡 | 200ms | `ease-in-out` | 卡片边框变色、阴影变化、导航高亮切换 |
| 展开/收起 | 300ms | `ease-in-out` | 项目卡片展开、移动端菜单 |
| 入场动效 | 500ms | `ease-out` | fade-in 入场（仅首屏可见元素） |
| 滚动 | 600ms | `ease-in-out` | 锚点平滑滚动 |

### 2.2 统一 CSS Transition

```css
/* 全局过渡变量 */
:root {
  --transition-fast: 150ms ease-out;
  --transition-normal: 200ms ease-in-out;
  --transition-slow: 300ms ease-in-out;
  --transition-enter: 500ms ease-out;
}
```

对应 Tailwind 配置：
```js
// tailwind.config.ts
transitionDuration: {
  fast: '150ms',
  normal: '200ms',
  slow: '300ms',
  enter: '500ms',
}
```

## 三、页面级交互

### 3.1 Hero 首屏

| 交互 | 触发 | 行为 | 时长 |
|---|---|---|---|
| 入场动效 | 页面加载完成 | Hero 文字区域从下方 20px fade-in + 上移 | 500ms |
| CTA 按钮 hover | 鼠标悬停 | 背景色加深 `blue-500 → blue-600`，微上移 1px | 150ms |
| CTA 按钮 active | 鼠标按下 | 背景色 `blue-700`，无位移 | 0ms |
| CTA 按钮点击 | 点击 | 平滑滚动到 `#projects`，偏移 -80px（导航栏高度） | 600ms |

**入场动效实现：**
```
Hero 区域初始状态: opacity: 0; transform: translateY(20px)
Hero 区域进入后: opacity: 1; transform: translateY(0)
transition: opacity 500ms ease-out, transform 500ms ease-out
```

### 3.2 导航栏

| 交互 | 触发 | 行为 | 时长 |
|---|---|---|---|
| 导航阴影 | 页面滚动 > 100px | 导航栏底部出现阴影 `shadow-sm` | 200ms |
| 导航阴影消失 | 页面滚动 < 100px | 阴影消失 | 200ms |
| 链接 hover | 鼠标悬停 | 文字色 `gray-600 → blue-500` | 150ms |
| 当前区域高亮 | Intersection Observer 触发 | 对应链接文字变蓝 + 底部 2px 蓝色下划线 | 200ms |
| 下载按钮 hover | 鼠标悬停 | 背景色加深，微上移 1px | 150ms |
| 姓名点击 | 点击 | 平滑滚动到顶部 `window.scrollTo({top: 0})` | 600ms |

**导航高亮切换逻辑：**
```
1. IntersectionObserver 监听所有 Section（threshold: 0.3）
2. 当某个 Section 可见比例 > 30% 时，标记为 active
3. 如果有多个 Section 同时可见，取第一个（最靠上的）
4. Hero 进入视口时，所有链接恢复默认色（不标记任何区域）
5. 仅 "项目作品"、"关于我"、"文章" 三个链接参与高亮
```

### 3.3 移动端菜单

| 交互 | 触发 | 行为 | 时长 |
|---|---|---|---|
| 菜单展开 | 点击汉堡按钮 ☰ | 菜单从顶部滑入，覆盖全屏，背景半透明遮罩 | 300ms |
| 菜单收起 | 点击 ✕ 或菜单项 | 菜单滑出消失 | 300ms |
| 菜单项 hover | 鼠标悬停 | 背景变浅灰 | 150ms |
| 菜单项点击 | 点击 | 平滑滚动到对应区域 + 关闭菜单 | 600ms + 300ms |

**移动端菜单实现：**
```
展开态: translateY(0), opacity: 1
折叠态: translateY(-100%), opacity: 0
transition: all 300ms ease-in-out
菜单打开时 body 添加 overflow: hidden 防止背景滚动
```

**菜单遮罩：**
```
背景: rgba(0, 0, 0, 0.5)
点击遮罩区域 → 关闭菜单
```

### 3.4 项目卡片 — 手风琴模式

| 交互 | 触发 | 行为 | 时长 |
|---|---|---|---|
| 卡片 hover（折叠态） | 鼠标悬停 | 边框色 `gray-200 → blue-300`，阴影 `shadow-sm → shadow-md` | 200ms |
| 展开卡片 | 点击"展开"按钮或卡片头部 | 当前卡片展开，其他卡片收起；展开按钮变为"收起" | 300ms |
| 收起卡片 | 点击"收起"按钮 | 卡片折叠回折叠态 | 300ms |
| 展开状态切换 | 点击另一张卡片 | 当前展开的卡片收起，新卡片展开 | 300ms |

**展开/收起动效实现：**
```
使用 CSS grid-template-rows 或 max-height 过渡:

折叠态: grid-template-rows: 0fr (或 max-height: 0)
展开态: grid-template-rows: 1fr (或 max-height: 2000px)
transition: grid-template-rows 300ms ease-in-out

注意：避免使用 height: auto → height: 0 的过渡（CSS 不支持），
推荐使用 grid-template-rows 方案（现代浏览器均支持）
```

**展开按钮图标旋转：**
```
折叠态: 箭头向下 ▼ (rotate(0deg))
展开态: 箭头向上 ▲ (rotate(180deg))
transition: transform 200ms ease-in-out
```

```

| 交互 | 触发 | 行为 | 时长 |
|---|---|---|---|
| 下载按钮点击 | 点击 | 触发 `react-to-print`，打开浏览器打印对话框 | — |

```

## 四、滚动行为

### 4.1 锚点平滑滚动

```css
/* 全局平滑滚动 */
html {
  scroll-behavior: smooth;
}
```

| 触发 | 行为 | 偏移量 |
|---|---|---|
| 点击导航链接 | 滚动到对应 Section | -80px（导航栏高度补偿） |
| 点击 Hero CTA | 滚动到 `#projects` | -80px |
| 点击导航栏姓名 | 滚动到顶部 | 0 |

### 4.2 滚动监听（Intersection Observer）

```
配置:
- root: null (视口)
- rootMargin: '-80px 0px 0px 0px' (导航栏高度补偿)
- threshold: 0.3 (30% 可见即触发)

监听目标:
- #hero        → 无高亮
- #projects    → "项目作品" 高亮
- #about       → "关于我" 高亮
- #articles    → "文章" 高亮
- #contact     → 无高亮
```

### 4.3 导航栏阴影

```
监听 scroll 事件:
- scrollY > 100 → 导航栏添加 shadow-sm
- scrollY ≤ 100 → 导航栏移除阴影

注意: 使用被动事件监听器 (passive: true) 避免影响滚动性能
```

## 五、状态切换交互

### 5.1 文章模块显隐

```
条件: articles 数据数组长度
  > 0 → 渲染 #articles Section + 导航栏显示"文章"链接
  = 0 → 不渲染 #articles Section + 导航栏隐藏"文章"链接

触发: 页面加载时判断，无需运行时切换
```

### 5.2 图片加载

```
正常加载: 图片淡入显示
  opacity: 0 → opacity: 1, transition: 300ms

加载失败: 显示占位色块
  bg-gray-100, 保持原始宽高比
  不显示破碎图片图标
```

### 5.3 页面加载

```
初次加载: Hero 区域 fade-in 入场（500ms）
后续导航: 无动效（纯静态站点，无路由切换）
```

## 六、键盘可访问性

| 操作 | 按键 | 行为 |
|---|---|---|
| 导航链接聚焦 | Tab | 按顺序聚焦导航链接，可见 focus ring（蓝色轮廓） |

**Focus Ring 样式：**
```
outline: 2px solid #3B82F6 (blue-500)
outline-offset: 2px
border-radius: 4px
```

## 七、移动端特殊交互

### 7.1 触摸反馈

| 交互 | 行为 |
|---|---|
| 按钮点击 | 添加 `touch-action: manipulation` 消除 300ms 延迟 |
| 卡片点击 | 点击卡片头部区域展开/收起，增大点击区域至整行 |
| 菜单点击 | 菜单项高度 ≥ 48px，满足触摸目标最小尺寸 |

### 7.2 手势适配

| 手势 | 行为 |
|---|---|
| 垂直滑动 | 正常滚动页面 |
| 水平滑动 | 无特殊行为（无横向滚动内容） |
| 双击 | 无特殊行为（不阻止默认缩放） |

### 7.3 安全区域

```
iPhone X+ 刘海屏适配:
- 导航栏: padding-top: env(safe-area-inset-top)
- 底部内容: padding-bottom: env(safe-area-inset-bottom)
- 移动端菜单: 全屏展开时避开安全区域
```

## 九、性能注意事项

| 注意点 | 措施 |
|---|---|
| 避免 layout thrashing | 使用 `transform` 和 `opacity` 做动画，不用 `height`/`width`/`top`/`left` |
| GPU 加速 | 动画元素添加 `will-change: transform, opacity`（仅在动画期间） |
| 滚动性能 | scroll 监听器使用 `passive: true` |
| Intersection Observer | 使用原生 API，不引入第三方库 |
| 减少重绘 | 导航栏阴影用 `box-shadow` 过渡，不改变布局 |
| 移动端优化 | 避免 `backdrop-filter` 在低端机上使用（降级为纯白背景） |
