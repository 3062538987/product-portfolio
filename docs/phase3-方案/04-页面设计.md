## 一、设计原则

| 原则 | 说明 |
|---|---|
| 一屏一焦点 | 每个区域只传达一个核心信息，避免信息过载 |
| 扫描优先 | 面试官先扫读（3秒），再决定是否深读（2-3分钟），折叠态信息密度要高 |
| 视觉降噪 | 去掉一切非必要装饰，让内容本身说话 |
| 层级清晰 | 通过字号、字重、间距、颜色建立 3 级信息层级 |
| 克制动效 | 仅保留 fade-in 入场动效和手风琴展开动效，不喧宾夺主 |

## 二、全局布局规范

### 2.1 栅格系统

```
桌面端 (≥1024px):
┌──────────────────────────────────────────────┐
│               max-width: 960px                │
│              (内容区，居中)                    │
│           auto margin left/right              │
└──────────────────────────────────────────────┘

平板端 (768px - 1023px):
┌─────────────────────────────────┐
│         max-width: 720px         │
│     (内容区，居中，左右留白)      │
└─────────────────────────────────┘

移动端 (< 768px):
┌──────────────────────┐
│  max-width: 100%      │
│  padding: 16px 左右   │
└──────────────────────┘
```

### 2.2 间距系统

| 层级 | 值 | 用途 |
|---|---|---|
| xs | 8px | 紧凑元素间距（标签、图标与文字） |
| sm | 16px | 常规元素间距（卡片内边距） |
| md | 24px | 组件间距（导航项、卡片之间） |
| lg | 48px | 区块内间距（标题与内容） |
| xl | 80px | 区块间距（Section 之间的留白） |
| 2xl | 120px | 大区块间距（Hero 与项目之间） |

### 2.3 字号层级

| 层级 | 桌面端 | 移动端 | 用途 |
|---|---|---|---|
| H1 | 48px / Bold | 32px / Bold | 姓名（Hero） |
| H2 | 36px / Bold | 28px / Bold | 区域标题 |
| H3 | 24px / Semibold | 20px / Semibold | 项目名称 |
| H4 | 20px / Semibold | 18px / Semibold | 文章标题 |
| Body-L | 18px / Regular | 16px / Regular | 定位语、指标数字 |
| Body | 16px / Regular | 15px / Regular | 正文 |
| Body-S | 14px / Regular | 13px / Regular | 辅助文字、日期 |
| Caption | 12px / Regular | 12px / Regular | 标签、指标说明 |

## 四、响应式断点设计

| 断点 | 宽度 | 布局变化 |
|---|---|---|
| 桌面端 | ≥1024px | 内容区 960px 居中，项目卡片 3 列指标 |
| 平板端 | 768-1023px | 内容区 720px 居中，间距缩小，字号略降 |
| 移动端 | <768px | 内容区全宽 + 16px 内边距，导航改为汉堡菜单，项目卡片全宽堆叠，指标 3 列改 2 列或单列 |

### 关键断点行为差异

| 元素 | 桌面端 | 移动端 |
|---|---|---|
| 导航栏 | 水平展开 | 汉堡菜单 |
| 项目卡片指标 | 3 列横排 | 3 列横排（375px 以上）或 1 列竖排（极窄） |
| Hero 字号 | 48px / 36px | 32px / 20px |
| 区域间距 | 120px | 80px |
| 卡片内边距 | 24px | 16px |
| About 文本 | 居中对齐 | 左对齐 |
| 联系方式 | 横排 | 竖排居中 |

## 五、交互状态定义

### 5.1 项目卡片手风琴

```
状态 1: 全部折叠（默认）
┌──────────────┐
│ 卡片 1 [▼]   │
├──────────────┤
│ 卡片 2 [▼]   │
├──────────────┤
│ 卡片 3 [▼]   │
└──────────────┘

状态 2: 卡片 1 展开
┌──────────────┐
│ 卡片 1 [▲]   │
│ ╔══════════╗ │
│ ║ 详细内容  ║ │
│ ╚══════════╝ │
├──────────────┤
│ 卡片 2 [▼]   │
├──────────────┤
│ 卡片 3 [▼]   │
└──────────────┘

状态 3: 点击卡片 2 → 卡片 1 收起，卡片 2 展开
┌──────────────┐
│ 卡片 1 [▼]   │
├──────────────┤
│ 卡片 2 [▲]   │
│ ╔══════════╗ │
│ ║ 详细内容  ║ │
│ ╚══════════╝ │
├──────────────┤
│ 卡片 3 [▼]   │
└──────────────┘
```

**展开/收起动效：**
- 使用 CSS `max-height` transition（或 `grid-template-rows`）
- 时长：300ms
- 缓动：`ease-in-out`
- 展开时卡片边框色过渡到 blue-300

### 5.2 导航高亮

```
Intersection Observer 监听每个 Section
  │
  ├── Hero 进入视口 → 所有导航链接为默认色
  ├── Projects 进入视口 → "项目作品" 高亮
  ├── About 进入视口 → "关于我" 高亮
  ├── Articles 进入视口 → "文章" 高亮
  └── Contact 进入视口 → 无高亮（无对应导航项）
```

| 文章数据为空 | `#articles` 整个 Section 隐藏，导航栏"文章"链接隐藏 |
| 项目数据为空 | 理论上不应发生，数据文件至少包含 2 个项目 |
| 图片加载失败 | 显示占位色块 (`bg-gray-100`)，不影响布局 |
| 移动端横屏 | 按平板端断点处理，750px 以上使用平板布局 |
| 超长文本 | 项目描述不做截断，信任内容编辑；定位语限制 1 行 |
| 打印场景 | 使用 `@media print` 隐藏非必要元素，仅显示 PDF 导出组件 |
