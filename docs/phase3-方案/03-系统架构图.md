## 三、自定义 Hooks

```
useScrollSpy
├── 输入: sectionIds (string[])
├── 输出: activeSection (当前可见区域 ID)
├── 实现: IntersectionObserver
└── 用途: 导航栏高亮当前所在区域

useAccordion
├── 输入: items (项目卡片数组)
├── 输出: expandedIndex (当前展开的卡片索引), toggle(index)
├── 实现: useState
└── 用途: 手风琴模式，同一时间只展开一个项目卡片
```

## 四、数据模型

### profile.ts
```typescript
interface Profile {
  name: string;           // 姓名
  title: string;          // 岗位，如 "B端产品经理"
  tagline: string;        // 一句话定位
  bio: string;            // 个人陈述
  careerGoal: string;     // 职业目标
  email: string;          // 邮箱
  linkedin: string;       // LinkedIn 链接
}
```

### projects.ts
```typescript
interface Project {
  id: string;             // 唯一标识
  name: string;           // 项目名称
  summary: string;        // 一句话概述
  metrics: {              // 3个关键指标（折叠态展示）
    label: string;
    value: string;        // 如 "+35%"
    description: string;
  }[];
  background: string;     // 背景与挑战（含问题发现方式、核心矛盾、为什么之前没解决）
  myRole: {               // 我的角色与推动
    responsibilities: string;  // 具体职责
    crossTeam: string;         // 跨部门协作
    biggestChallenge: string;  // 最大挑战
  };
  solution: {             // 方案与决策
    alternatives: string;      // 方案对比（A vs B，为什么选B）
    coreChanges: string[];     // 核心改动（3-5条）
    tradeOffs: string;         // 主动放弃了什么
    constraints: string;       // 技术/业务约束
  };
  metricsComparison: {    // 数据对比
    chartImage: string;        // Power BI 导出的图表图片路径
    beforeAfter: {             // 对比数据表
      label: string;
      before: string;
      after: string;
    }[];
    rationale: string;         // 指标选择理由
    iteration: string;         // 迭代说明（上线后改了几版，每版改了什么）
  };
  reflection: string;     // 复盘与反思（重来会怎么不同、学到的方法论、认知改变）
  deliverables: {         // 相关交付物（可选，0-N个）
    name: string;               // 交付物名称，如 "PRD 文档"
    icon: string;               // 图标类型，如 "file-text" / "image" / "link"
    previewUrl?: string;        // 在线预览链接
    downloadUrl?: string;       // 下载链接
  }[];
}

type ProjectsData = Project[];  // 4个
```

### articles.ts
```typescript
interface Article {
  title: string;          // 标题
  date: string;           // 发布日期
  summary: string;        // 摘要
  url: string;            // 外部链接
}

type ArticlesData = Article[];   // 0-2篇
```

## 五、部署架构

```
┌──────────────┐     git push      ┌──────────────┐

│  (localhost) │                    │   Repository │

                                           │
                                           ▼
                                    ┌──────────────┐

                                           │
                                    GitHub Pages
                                           │
                                           ▼
                              ┌──────────────────────┐
                              │  3062538987.github   │
                              │  .io/product-        │
                              │  portfolio           │
                              └──────────────────────┘
```

### GitHub Actions 流程

```yaml
# .github/workflows/deploy.yml
on:
  push:
    branches: [master]

jobs:
  deploy:
    steps:
      1. Checkout 代码
      2. 安装 Node.js 18
      3. npm install
      4. npm run build (Vite 构建 → dist/)
      5. 部署到 gh-pages 分支 (peaceiris/actions-gh-pages)
```
