## 二、术语定义

| 术语 | 说明 |
|---|---|
| 作品集 | 指本网站，展示个人 B 端产品项目的在线平台 |
| 项目卡片 | 网站中展示单个产品项目的折叠式内容区块 |
| STAR | Situation-Task-Action-Result 项目描述框架 |
| PDF 导出 | 将网站内容渲染为 A4 排版的 PDF 文件供下载 |

## 三、项目背景

2027 届秋招 B 端产品经理求职中，简历能承载的信息有限，PDF 作品集不便于查阅和更新。需要一个在线作品集网站，作为简历的深度补充，让面试官看到简历之外的「我是怎么做的、为什么这么做」。

同时，将网站本身作为一个产品项目来执行，完整体现从需求到上线的产品全流程能力。

## 四、项目目标

- **核心目标**：让面试官看完后留下「这个人很适合做产品」的印象，获得面试邀请
- **次要目标**：锻炼产品全流程能力，产出可复用的项目案例；锻炼 Figma 原型设计能力
- **长期目标**：网站可作为个人品牌持续运营，支持搜索引擎收录

## 五、项目范围

### 做（In Scope）

- 单页作品集网站，展示 2-3 个 B 端产品项目
- 项目卡片折叠/展开交互
- 响应式布局（桌面 + 移动端）
- 一键导出 PDF 简历
- 数据文件驱动的内容管理
- 完整的 8 阶段产品流程文档

### 不做（Out of Scope）

- 后端服务、数据库、用户登录
- 博客系统（CMS）、评论功能
- 多语言支持
- 自定义域名邮箱
- 动画特效（仅保留 fade-in 微动效）

## 六、目标用户

参见 [1.1 用户画像](./01-用户画像.md)，三类用户：
1. 面试官（HR + 业务面试官）— 核心用户
2. 求职者（我自己）— 内容生产者
3. 间接用户（同行/同学/社交分享者）— 次要用户

## 九、非功能需求

| 维度 | 要求 |
|---|---|
| 加载性能 | 首屏 FCP < 1.5s，LCP < 2.5s，Lighthouse Performance > 90 |
| 浏览器兼容 | Chrome、Edge、Safari 最新两个版本 |
| 响应式 | 桌面端 1280px+、平板 768px、手机 375px 三个断点 |
| 可维护性 | 内容与代码分离，修改数据文件无需改代码 |
| 安全性 | 纯静态页面，无后端，无 XSS 风险 |
| SEO | 语义化 HTML，meta 标签完整，支持 Open Graph |
| 可访问性 | 语义化标签，图片有 alt，键盘可导航 |

## 十、成功指标

| 指标 | 目标值 | 衡量方式 |
|---|---|---|
| 面试邀请率 | 作品集链接被点击后，进入下一轮面试的比例提升 | 面试后统计 |
| 面试提及率 | 面试官在面试中主动提及作品集内容 | 面试后统计 |
| 网站加载速度 | 首屏 < 2 秒，Lighthouse > 90 | Lighthouse 评分 |
| PDF 下载量 | 有实际下载行为 | Google Analytics |
| 项目完读率 | 面试官展开至少一个项目并阅读完整内容 | 埋点统计 |

## 十二、约束条件

- 时间：1 周内完成从需求到上线全流程
- 技术：React + Vite + Tailwind CSS，纯前端静态页面
- 部署：GitHub Pages，推送即部署，免费 HTTPS
- 内容：我自行提供项目素材和个人信息
- 原型工具：Figma（锻炼软件能力）
